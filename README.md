# Baltimera

Статический сайт Baltimera. Готовый сайт находится в dist/. Для хостинга используйте содержимое dist/.

Включены изображения, шрифты, 3D-модель, JavaScript, CSS и исходные материалы. generate.py генерирует HTML.

Форма проверяет данные локально. Отправку заявок нужно подключить отдельно.
